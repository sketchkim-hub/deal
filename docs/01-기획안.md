# 오늘의특가 — 기획안

쿠팡에서 **15% 이상 할인 중인 상품**만 골라 보여주고, 가격이 바뀌면 반영하는 쿠팡 파트너스 제휴 사이트.

---

## 1. 목표

| 목표 | 기준 |
| --- | --- |
| 방문자가 "지금 싸게 살 수 있는 것"을 3초 안에 찾게 한다 | 첫 화면에 할인율·가격·썸네일이 보이는 카드 8개 이상 |
| 가격 정보를 믿을 수 있게 한다 | 모든 카드에 "가격 확인 시각" 표시, 48시간 넘게 갱신 안 된 상품은 자동 숨김 |
| 파트너스 수익 | 모든 구매 버튼은 파트너스 단축링크로 이동 (클릭·구매 통계는 파트너스 리포트) |
| 운영 부담 최소화 | 쿠팡 상품 페이지에서 버튼 한 번이면 상품명·사진·가격·할인율이 채워짐 |

## 2. 제약과 해결 방법

| 제약 | 해결 |
| --- | --- |
| 쿠팡이 프로그램의 자동 접속을 차단 (한국 가정용 IP + 실제 브라우저로도 HTTP 403 확인) | 차단을 우회하지 않습니다(약관 위반·파트너스 계정 정지 위험). 대신 **사람이 연 쿠팡 페이지**에서 크롬 북마크 버튼 **'⚡ 특가 담기'** 를 누르면 화면에 보이는 값을 관리자 대시보드로 보냅니다. |
| 쿠팡 파트너스 Open API 미승인 | **지금**: '특가 담기' + 파트너스 단축링크 붙여넣기.<br>**API 승인 후**: `.env`에 키만 넣으면 단축링크 자동 생성과 골드박스 특가 후보 수집(하루 3번)이 켜집니다. 코드는 이미 들어 있습니다. |
| 서버 운영 비용·관리 부담 | 사이트는 **GitHub Pages 또는 Firebase Hosting**(무료)에 정적 페이지로 게시합니다. 담거나 고칠 때마다 30초 뒤 자동으로 올립니다. 집 PC가 꺼져도 사이트는 계속 열립니다. |
| 쿠팡 페이지 구조 변경 | 버튼이 여러 방식(메타 태그 → JSON-LD → 화면 요소)을 차례로 시도하고, 못 읽은 값은 담기 창에서 직접 입력할 수 있습니다. 화면 요소 선택자는 `src/coupang/selectors.js` 한 곳에 있습니다. |

## 3. 핵심 기능

### 3.1 방문자 화면
- **홈(오늘의 특가)**: 할인율순 카드 그리드, 카테고리·할인율(15/30/50%+) 필터, 정렬(할인율/방금 내린/절약액/낮은 가격/최신)
- **"방금 가격 내려갔어요"** 가로 스크롤 영역: 직전 확인보다 가격이 내려간 상품(24시간 이내)
- **가격 업데이트 시각**: 상단과 모든 카드에 실제 확인 시각 표시
- **상품 상세**: 큰 썸네일, 가격 변동 그래프, 기록상 최저가, 공유 버튼(카카오톡 등 모바일 공유 시트)
- 모든 페이지 상단·하단에 파트너스 고지 문구

### 3.2 관리자 대시보드 (집 PC의 `http://127.0.0.1:3000/admin`, 그 PC에서만 열림)
- **현황 카드**: 사이트 노출 / 갱신 필요 / 노출 안 됨 / 전체 — 누르면 아래 표가 해당 상품으로 걸러짐
- **사이트 게시**: 마지막 게시 결과, "지금 게시" 버튼
- **'특가 담기' 버튼 설치 · 사용법**: 북마크바로 끌어다 놓는 버튼과 단계별 안내
- **🔄 갱신 필요 목록**: 20시간 넘게 가격을 확인하지 않은 노출 상품, 오래된 순. "쿠팡 열기" → '특가 담기'로 갱신
- **상품 표**: 상태·가격·할인율·확인 시각·"n시간 뒤 숨김" 경고, 쿠팡 열기 / 숨김 / 편집(가격·정가·링크·사진·카테고리) / 삭제
- **후보**(API 승인 후): 골드박스 특가 중 15% 이상

### 3.3 '특가 담기' 창
- **새 상품**: 읽어 온 상품명·사진·판매가·정가·할인율·로켓배송·품절을 보여 주고 고칠 수 있음 → 파트너스 단축링크 붙여넣기 → 저장
  - 단축링크가 다른 상품의 링크면 저장을 막고 알려 줌
  - 할인율 15% 미만·품절이면 "노출되지 않아요" 미리 안내
- **이미 담은 상품**: "가격 업데이트" 창 — 이전/지금 가격 비교(▼ 내림 / ▲ 오름) 후 저장

### 3.4 노출 규칙
| 상태 | 처리 |
| --- | --- |
| 할인율 ≥ 15% | 노출 |
| 할인율 < 15% | 숨김. 다시 담았을 때 15% 이상이면 자동 복귀 |
| 품절 | 숨김 |
| 48시간 넘게 갱신 안 됨 | 숨김 (`STALE_HOURS`). 다시 담으면 복귀 |
| 가격 변동 | 직전 가격을 저장해 "▼ 3,000원 내림" 표시, 이력은 최근 90회 보관 |

## 4. 시스템 구성

```
┌─────────────────────────── 집 PC ───────────────────────────┐
│ 크롬: 쿠팡 상품 페이지 ──[⚡ 특가 담기]──▶ 담기 창(확인·저장)   │
│                                              │               │
│ npm start: 관리자 대시보드 127.0.0.1:3000 ◀────┘               │
│            data/db.json (상품·가격 이력)                       │
│            정적 사이트 생성(dist/) ─▶ 자동 게시 ────────────────┼──┐
└──────────────────────────────────────────────────────────────┘  │
                                                                  ▼
                       [GitHub Pages 또는 Firebase Hosting] ◀── 방문자 (내 도메인, HTTPS)
```

- 런타임: Node.js 20+, 외부 의존성 `cheerio` 1개
- DB: JSON 파일 1개 (상품 수천 개까지 충분, 백업은 파일 복사)
- 사이트: 완성된 HTML 파일만 게시 → 검색엔진 노출·첫 화면 속도에 유리, 해킹될 서버가 없음
- 구매 버튼은 파트너스 단축링크로 바로 연결

## 6. 준수 사항 (중요)

1. **파트너스 고지 문구**: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." — 모든 페이지 상단과 하단에 자동 표시됩니다. 지우지 마세요.
2. **가격 표시**: 가격은 확인 시점 기준이며 실제와 다를 수 있다는 안내와 확인 시각을 함께 표시합니다. 자동 확인이 없는데 "다음 가격 확인" 같은 표시는 하지 않습니다.
3. **자동 수집 금지**: 쿠팡의 봇 차단을 우회하지 않습니다. `MONITOR_MODE=on`(자동 확인)은 코드에 남아 있지만 기본으로 꺼져 있고 쓰지 않는 것을 권장합니다.
4. 가짜 후기, 허위 "마감 임박", 부풀린 조회수 같은 표시는 넣지 않았습니다.

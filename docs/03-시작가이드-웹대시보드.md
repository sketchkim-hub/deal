# 시작 가이드 — 웹 대시보드 (설치 없이 브라우저로만)

## 구성

```
어느 PC든 크롬
 ├ 쿠팡 상품 페이지 ──[⚡ 특가 담기]──▶ 담기 창 (웹)
 └ 관리자 대시보드  https://sketchkim-hub.github.io/deal/admin/
                        │ 저장 = GitHub 저장소의 content/db.json 에 기록
                        ▼
              GitHub Actions 가 1~2분 안에 사이트를 새로 만들어 게시
                        ▼
              공개 사이트  https://sketchkim-hub.github.io/deal/   (도메인 연결 가능)
```

- **PC에 설치할 것이 없습니다.** 명령 프롬프트, Node.js, `npm start` 모두 필요 없습니다.
- **PC를 바꿔도** 대시보드 주소로 들어가 토큰을 붙여넣고 '특가 담기' 버튼만 다시 끌어다 놓으면 됩니다.
- 사이트는 3시간마다 자동으로 다시 만들어져, 오래된 가격(48시간) 숨김 같은 규칙이 저장하지 않아도 반영됩니다.
- 비용: 0원 (GitHub Pages · Actions 무료 범위).

---

## 1. 처음 한 번: GitHub 설정 (5분)

### 1-1. 저장소를 공개로 바꾸기
무료 GitHub 계정의 Pages는 **공개 저장소**에서만 동작합니다.

1. https://github.com/sketchkim-hub/deal → **Settings**
2. 맨 아래 **Danger Zone** → **Change repository visibility** → **Change to public**

공개되는 것은 사이트 코드와 담은 상품 목록(가격·링크)뿐입니다. 토큰이나 비밀번호는 저장소에 들어가지 않습니다.

### 1-2. Pages 켜기
1. 저장소 **Settings** → 왼쪽 **Pages**
2. **Build and deployment → Source** 를 **GitHub Actions** 로 선택
3. 저장소 **Actions** 탭 → 왼쪽 **Publish site** → 오른쪽 **Run workflow** → **Run workflow**
4. 1~2분 뒤 초록색 체크가 뜨면 완료 → https://sketchkim-hub.github.io/deal/ 이 열립니다.

### 1-3. 대시보드용 토큰 만들기
1. https://github.com/settings/personal-access-tokens/new
2. **Token name**: `teukga-admin` · **Expiration**: 원하는 기간(예: 1년, 만료되면 새로 만들면 됨)
3. **Repository access**: *Only select repositories* → `sketchkim-hub/deal`
4. **Permissions** → Repository permissions
   - **Contents**: Read and write
   - **Actions**: Read-only (대시보드에 "게시 완료/반영 중" 표시용)
5. **Generate token** → `github_pat_...` 값을 복사해 **메모장이나 비밀번호 관리자에 보관**하세요. (다른 PC에서 다시 씁니다)

## 2. 대시보드 로그인과 '특가 담기' 버튼 설치 (PC마다 한 번)

1. 크롬에서 **https://sketchkim-hub.github.io/deal/admin/** 을 엽니다. 즐겨찾기에 추가해 두세요.
2. 토큰을 붙여넣고 **로그인**.
3. **⚡ '특가 담기' 버튼 설치 · 사용법** 을 펼칩니다.
4. `Ctrl`+`Shift`+`B` 로 북마크바를 켜고, 빨간 **⚡ 특가 담기** 버튼을 **꾹 누른 채 끌어서** 북마크바에 놓습니다.
   - 끌기가 어려우면: 버튼 오른쪽 클릭 → **링크 주소 복사** → 북마크바 빈 곳 오른쪽 클릭 → **페이지 추가** → 이름 `⚡ 특가 담기`, URL 칸에 붙여넣기 → 저장

## 3. 매일 쓰는 법

**새 특가 담기**
1. 쿠팡에서 할인 중인 **상품 상세 페이지**를 엽니다.
2. 북마크바의 **⚡ 특가 담기** → 작은 창에 상품명·사진·가격·할인율이 채워집니다.
3. 쿠팡 파트너스에서 **이 상품**의 단축링크를 만들어 붙여넣고 **저장하고 사이트에 올리기**.
4. 1~2분 뒤 사이트에 나타납니다. 대시보드 위쪽 **사이트 게시**에서 "반영 중 → 게시 완료"를 볼 수 있습니다.

**가격 갱신 (하루 한 번 정도)**
- 대시보드 **🔄 갱신 필요** 목록 → **쿠팡 열기** → **⚡ 특가 담기** → **업데이트 저장**.
- 이미 담은 상품에서 버튼을 누르면 자동으로 "가격 업데이트" 창이 뜨고 이전 가격과 비교해 보여 줍니다.

**고치기·숨기기·삭제**: 대시보드 상품 표의 **편집 / 숨김 / 삭제**.

## 4. 도메인 연결 (선택)

1. 가비아·후이즈 등에서 도메인 구입 (예: `todayteukga.com`)
2. DNS 설정 (가비아: My가비아 → 도메인 → DNS 관리):

   | 타입 | 호스트 | 값 |
   | --- | --- | --- |
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | `sketchkim-hub.github.io.` |

3. 저장소 **Settings → Pages → Custom domain** 에 도메인 입력 → Save → 인증서 발급 후 **Enforce HTTPS** 체크
4. **Actions → Publish site → Run workflow** 로 한 번 다시 게시 (사이트 주소가 새 도메인으로 바뀝니다)
5. 이후 대시보드 주소는 `https://도메인/admin/` 입니다. **'특가 담기' 버튼도 새 주소로 다시 끌어다 놓아야** 합니다.

한글 도메인은 DNS·GitHub 설정에 퓨니코드(`xn--...`)로 입력합니다. DNS 반영에는 최대 24시간 걸릴 수 있습니다.

## 5. 사이트 설정 바꾸기

저장소의 `site.config.json` 을 GitHub 웹에서 연필 아이콘으로 고치고 **Commit changes** 하면 1~2분 뒤 반영됩니다.

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `SITE_NAME` | 사이트 이름 | 오늘의특가 |
| `MIN_DISCOUNT` | 노출 최소 할인율(%) | 15 |
| `STALE_HOURS` | 이 시간 동안 갱신 안 한 상품은 숨김 | 48 |
| `REFRESH_HOURS` | '갱신 필요' 목록에 올라가는 기준 | 20 |

## 6. 백업

모든 데이터는 저장소의 `content/db.json` 한 파일이고, 저장할 때마다 GitHub에 기록(커밋)이 남습니다. 실수로 지워도 저장소 **History**에서 이전 버전을 되살릴 수 있습니다.

## 7. 쿠팡 파트너스 API 승인 후

저장소 **Settings → Secrets and variables → Actions** 에 `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` 를 등록하면 자동 후보 수집을 붙일 수 있습니다(추가 작업 필요 — 승인되면 알려 주세요).

## 8. 문제 해결

| 증상 | 조치 |
| --- | --- |
| 대시보드 주소가 404 | 1-1(공개), 1-2(Pages 소스 = GitHub Actions, Run workflow) 확인 |
| "토큰이 올바르지 않거나 만료" | 1-3으로 새 토큰을 만들어 다시 로그인 |
| "쓰기 권한이 없습니다" | 토큰의 Contents 권한이 **Read and write** 인지, 저장소가 `sketchkim-hub/deal` 인지 확인 |
| 게시 상태가 안 보임 | 토큰에 **Actions: Read-only** 추가 (저장·게시 자체는 됨) |
| '특가 담기'를 눌러도 창이 안 뜸 | 주소창 오른쪽 팝업 차단 아이콘 → 쿠팡 팝업 **항상 허용** |
| 담기 창에 "쿠팡 상품 정보를 읽지 못했습니다" | 검색 결과가 아니라 **상품 상세 페이지**(주소에 `/vp/products/`)에서 누르기 |
| 가격·정가 칸이 비어 있음 | 화면의 값을 직접 입력 후 저장. 자주 그러면 쿠팡 화면 구조 변경 → 캡처해서 문의 (`src/shared/selectors.js` 수정) |
| 저장했는데 사이트에 안 보임 | 1~2분 기다린 뒤 새로고침. 할인율 15% 미만·품절이면 노출되지 않음. Actions 탭에서 빨간 X면 기록을 캡처해서 문의 |
| 도메인 연결 후 버튼이 안 됨 | 새 대시보드 주소에서 버튼을 다시 끌어다 놓기 |

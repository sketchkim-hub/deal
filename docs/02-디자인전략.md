# 오늘의특가 — 디자인 전략

## 1. 핵심 원칙: "숫자가 먼저 눈에 들어오게"

특가 사이트 방문자는 글을 읽지 않고 **훑습니다**. 시선이 가는 순서를 의도적으로 설계합니다.

```
① 할인율(47%)  →  ② 썸네일  →  ③ 판매가(12,900원)  →  ④ 절약액/원가  →  ⑤ 구매 버튼
```

| 요소 | 처리 |
| --- | --- |
| 할인율 | 카드에서 가장 큰 글자. 썸네일 왼쪽 위 빨간 배지 + 가격 옆에 한 번 더 |
| 판매가 | 굵은 검정 20px 이상. 숫자는 고정폭 숫자(tabular-nums)로 정렬 |
| 원가 | 작은 회색 취소선 — "원래 이 가격"이라는 기준점(앵커) 역할 |
| 절약액 | "7,000원 절약" — 퍼센트보다 금액이 더 와닿는 상품(고가품)에 효과적 |
| 구매 버튼 | 카드 전체 폭, 쿠팡 이동이 분명하게 "쿠팡에서 보기 →" |

## 2. 색상

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--hot` | `#F0282D` | 할인율, 핵심 강조. 한국 쇼핑에서 빨강 = 세일이라는 학습된 신호 |
| `--ink` | `#14151A` | 본문·가격. 순검정보다 살짝 부드러운 먹색 |
| `--flash` | `#FFD43B` | "방금 인하" 배지, 카운트다운. 빨강과 부딪히지 않는 보조 강조 |
| `--muted` | `#6B7280` | 원가, 확인 시각 등 보조 정보 |
| `--bg` | `#F3F4F6` | 배경. 흰 카드가 떠 보이도록 옅은 회색 |
| `--rocket` | `#1463F3` | 로켓배송 태그 (쿠팡의 파랑 계열로 익숙함 활용) |

- 강조색은 빨강 하나로 제한 — 모든 게 빨가면 아무것도 눈에 띄지 않습니다.
- 흰 카드 + 회색 배경으로 상품 사진이 주인공이 되게 합니다.

## 3. 타이포그래피
- **Pretendard** (한글 웹폰트, 무료) — 숫자 가독성이 좋고 한국 쇼핑몰에서 흔히 쓰여 익숙함
- 할인율 800 굵기, 가격 800, 제목 500
- 상품명은 2줄로 자르고(…) 카드 높이를 맞춰 격자가 흐트러지지 않게

## 4. 레이아웃 (모바일 우선)

유입의 70~80%는 모바일(카톡·커뮤니티 링크)이라고 가정합니다.

```
┌──────────────────────────────┐
│ 파트너스 고지 (얇은 띠)          │
│ ⚡오늘의특가   다음 확인 15:00 ⏱ │  ← 상단 고정
├──────────────────────────────┤
│ 오늘 15% 이상 할인만 모았어요    │  ← 어두운 배너: 특가 수·최대·평균 할인율
│ 특가 42개 · 최대 68% · 평균 31% │
├──────────────────────────────┤
│ [전체][식품][생활][가전]…  ←→  │  ← 상단 고정 필터 칩
│ [15%+][30%+][50%+]  정렬 ▾     │
├──────────────────────────────┤
│ 🔻 방금 가격 내려갔어요   ←→    │  ← 가로 스크롤
├──────────────────────────────┤
│ ┌──────┐ ┌──────┐            │
│ │47%   │ │32%   │            │  ← 2열(모바일) / 3열(태블릿) / 5열(PC)
│ │ 사진  │ │ 사진  │            │
│ │제목…  │ │제목…  │            │
│ │12,900│ │8,900 │            │
│ │[쿠팡→]│ │[쿠팡→]│            │
│ └──────┘ └──────┘            │
└──────────────────────────────┘
```

- 필터는 페이지 새로고침 없이 즉시 적용, 선택한 필터는 주소(URL)에 남아 공유 가능
- 썸네일은 정사각형, 지연 로딩(lazy)으로 첫 화면을 빠르게

## 5. 주목도·재방문 장치 (정직한 것만)

| 장치 | 근거 |
| --- | --- |
| **상단 "가격 업데이트" 시각** | 마지막으로 가격을 확인한 실제 시각. 자동 확인(`MONITOR_MODE=on`)을 켠 경우에만 "다음 가격 확인까지" 카운트다운으로 바뀜 — 일어나지 않을 확인을 약속하지 않음 |
| **"방금 인하" 배지** | 직전 확인보다 실제로 가격이 내려간 경우에만 표시 |
| **가격 변동 그래프(상세)** | "지금이 싼 편인지" 판단 근거 제공 → 신뢰 |
| **가격 확인 시각** | 모든 카드에 "15:00 확인" — 오래된 가격으로 인한 실망 방지 |
| **공유 버튼** | 모바일 공유 시트(카카오톡 등) 호출, 공유 미리보기에 상품 사진·할인율 노출 |

**넣지 않은 것**: 가짜 "마감 임박", 꾸며낸 "N명이 보는 중", 가짜 후기. 단기 클릭은 늘 수 있지만 신뢰를 잃고, 표시광고법 문제가 될 수 있습니다.

## 6. 접근성·품질
- 색만으로 정보를 전달하지 않음(인하 배지에 "▼"와 글자 함께)
- 버튼 터치 영역 44px 이상
- 외부 이동 링크는 `rel="sponsored nofollow noopener"` (검색엔진 정책 준수)
- 상품 이미지 `alt`에 상품명
